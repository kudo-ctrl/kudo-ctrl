Device requirements

Configure this fresh device so it meets all five requirements:

  1. Set the hostname to EDGE-1.
  2. Set the enable secret to Cisco123!.
  3. Protect console line 0 with password ConPass1 and require login.
  4. Protect VTY lines 0 through 4 with password VtyPass1 and require login.
  5. Enable password encryption.

Inspect your work from privileged EXEC mode before submitting.
